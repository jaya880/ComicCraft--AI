# Phase 06 – Project Testing

## Testing Objective

The ComicCraft application is tested to verify that the main features work correctly and produce the expected comic output.

## Testing Steps

### Test 1 – Application Launch
Open the ComicCraft application and verify that the main page loads correctly.

### Test 2 – User Input
Enter the required comic details:
- Story Prompt
- Character Name
- Setting
- Tone
- Art Style

### Test 3 – Comic Generation
Submit the inputs and verify that the system generates the comic story.

### Test 4 – Story Output
Check whether the generated story and panel content are displayed correctly.

### Test 5 – Image Generation
Verify that illustrations are generated for the comic panels.

### Test 6 – Comic Preview
Check whether the generated panels are displayed correctly in the comic preview.

### Test 7 – Export
Test the export functionality and verify that the generated comic can be downloaded.

## Expected Result

The application should accept the user's inputs, generate the comic story and illustrations, display the comic preview, and provide the final output for export.
